# Pushable Budding Amethyst

This mod allows you to push Budding Amethyst blocks with pistons. 

The implementation is simply taken from Gnembon's [Fabric Carpet](https://github.com/gnembon/fabric-carpet). Carpet mod adds a toggleable rule to allow for the same functionality. However that same rule also allows the player to mine Budding Amethyst blocks using Silk Touch tools. As I don't like that part of the rule, I separated out just the pushing functionality into its own mod.

There is also an [earlier mod](https://modrinth.com/mod/pushable-amethysts) by [clearKeep](https://codeberg.org/clearKeep) which does the same thing for older Minecraft versions (1.20 - 1.20.2).

## Build instructions

To build the mod yourself, clone the repository. Open the local repo in your IDE of choice (I'm using VS Code with the Java Extension bundle). Wait for Java and Gradle to set up, then build the project with `./gradlew build`.
